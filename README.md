# 🎓  Student Management System

A Java-based console application developed to manage student records, batches, grades, and academic reports efficiently.

## 📌 Project Overview

The ** Student Management System** is designed to simplify student and batch management activities. It allows users to register students, update student information, manage batches, update examination marks, calculate GPA, and generate academic reports through a menu-driven interface.

## ✨ Features

### 1. Student Management

* Add new students.
* Update student names and NIC numbers.
* View individual student profiles.
* Delete student profiles.
* Generate student registration numbers.
* Prevent duplicate student registrations.

### 2. Batch Management

* Add new batches.
* Update batch enrollment status.
* View all available batches.
* Display the number of students in each batch.
* Manage enrollment as Open or Closed.

### 3. Grade Management

* Update PRF examination marks.
* Update DBMS examination marks.
* Handle absent students.
* Identify examinations that have not been conducted.
* Calculate student GPA based on examination marks.

### 4. Report Generator

* Student Registration Report.
* Batch-wise Student Report.
* Industry Training Eligibility Report.
* Display student details, marks, and GPA.
* Sort student records by name.
